# Beauty Mirror — Live V1

PWA mobile avec caméra frontale, analyse faciale en direct via MediaPipe Face Landmarker et essais maquillage AR simples.

## Déploiement GitHub Pages
1. Décompresser le ZIP.
2. Envoyer tous les fichiers à la racine du dépôt GitHub.
3. Settings > Pages > Deploy from a branch > main / root.
4. Ouvrir l'URL GitHub Pages en HTTPS.
5. Autoriser la caméra.
6. Code d'accès : 071079.

## Important
La caméra nécessite HTTPS (GitHub Pages convient). La première ouverture nécessite Internet pour charger MediaPipe et son modèle.
Les teintes sont lues sur l'image caméra actuelle : l'éclairage et la balance des blancs du téléphone influencent donc la couleur observée.
